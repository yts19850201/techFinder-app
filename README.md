## v1.3.0 실행 방법

1. 배포 ZIP을 다운로드하고 **전체 압축을 해제**합니다.
2. `TechFinder_260917.exe`를 실행합니다. `_internal` 폴더를 EXE와 함께 유지하세요.
3. 검색 대상 폴더를 등록하고 **자료 갱신**을 누릅니다.
4. 기억나는 단어나 문장으로 자료를 검색합니다.

Windows 64비트용입니다. Python 별도 설치와 AI API 토큰 비용이 필요 없습니다. 코드 서명은 적용되지 않았습니다.

## 포함 기능

- 로컬·NAS 폴더 등록 및 선택
- PDF·HWP·HWPX·PPTX·DOCX·XLSX·텍스트 본문 검색과 이미지 OCR
- 변경된 파일 중심의 자료 갱신과 진행률 표시
- 정리된 UI, 배너, 제작자 블로그 링크

일부 도형·차트·삽입 개체와 OCR 결과는 누락되거나 부정확할 수 있으므로 원본을 확인하세요.

이 저장소는 **실행파일 배포 전용**입니다. 프로젝트 소스, 관리자 기능, 개인 검색 데이터는 포함하지 않습니다. 검색 자료는 사용자 PC에 저장됩니다.
